# soap-delivery
Sample of SOAP project with wsdl file for Sumy State University


## 🚀 Running
➡️1 step - is build project with maven 

➡️ 2 step - run `DeliveryPublisher.java` and check url `http://localhost:8080/delivery?wsdl` in browser

➡️ 3 step - run SOAP client with `DeliveryClient.java` and enjoy
